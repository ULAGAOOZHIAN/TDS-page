# Manufacturing Energy Flow — RAWGraphs Sankey

This repository contains a Sankey diagram created with RAWGraphs to visualize energy flows from sources to end uses in manufacturing.

- Author email (for verification): **24ds1000121@ds.study.iitm.ac.in**
- Tool: RAWGraphs (web app)
- Export: PNG, 512×512

## Files
- `chart.png` — final Sankey diagram
- `data.csv` — source data pasted into RAWGraphs

## How it was made
1. Pasted `data.csv` into RAWGraphs.
2. Chose **Sankey diagram**.
3. Mapped `source` → Source, `target` → Target, `flow` → Weight, `source` → Color.
4. Applied custom colors and labels.
5. Exported as 512×512 PNG.
